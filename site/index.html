HeicToClipboard

Right click a HEIC photo → C&C to JPEG → Ctrl+V. A tiny Windows tool that converts HEIC/HEIF images to JPEG and puts them on the clipboard, ready to paste into Discord, email, forums or any app that does not accept HEIC.

Install

Open PowerShell and run:

irm https://venes.org/heictoclipboard/install.ps1 | iex

This downloads the latest HeicToClipboard.exe, verifies its SHA-256 checksum, installs it to %LocalAppData%\Programs\HeicToClipboard and adds C&C to JPEG to the Explorer context menu for .heic and .heif files. No admin rights needed. Prefer manual setup? Download the exe with the button above and follow the instructions in the README.

Usage

  1. Right click one or more .heic / .heif files in Explorer
  2. Select C&C to JPEG
  3. Go to Discord or another app and press Ctrl+V

Starting HeicToClipboard.exe directly opens a settings window for output folder, max file size, JPEG quality, resolution cap and temp-file cleanup — and checks for updates.

Key features

  • One clipboard batch
    Select many files at once; all of them end up together on the clipboard.
  • Correct colors
    Wide-gamut photos (iPhone Display P3) are converted to sRGB so they look right everywhere.
  • Size-limit aware
    Picks the highest JPEG quality that fits under the size limit (9.8 MB by default, Discord-friendly).
  • No file clutter
    No JPEG files are written next to your originals; temp files clean themselves up.
  • Configurable
    Output folder, max file size, quality, longest-side cap and cleanup age.
  • Auto-update
    The settings window checks this page for new versions and updates in place.

Requirements

  • Windows 10 or Windows 11
  • HEIF Image Extensions from the Microsoft Store

If HEIF support is missing, the app shows a message explaining how to install it.

Privacy

  • No telemetry, no background services
  • Your images never leave your PC
  • The only network access is the update check against venes.org/heictoclipboard when you open the settings window

Updates and source code

The update feed is hosted at venes.org/heictoclipboard. Release files are latest.json and the versioned HeicToClipboard-x.y.z.exe. The source code is available on GitHub and released under the MIT license.
